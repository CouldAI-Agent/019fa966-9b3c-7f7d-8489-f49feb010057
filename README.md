# Describing People - Materi Ajar Bahasa Inggris Kelas 10

Aplikasi ini merupakan materi ajar interaktif untuk mata pelajaran Bahasa Inggris kelas 10 SLTA dengan topik "Describing People".

## Fitur Utama
- **Materi**: Penjelasan lengkap mengenai *Physical Appearance* (penampilan fisik) dan *Personality* (kepribadian).
- **Contoh Dialog**: Contoh percakapan sehari-hari yang menggunakan ungkapan mendeskripsikan seseorang.
- **Kosakata**: Daftar kosakata penting (*Adjectives*) yang sering digunakan.

## Teknologi
- Flutter
- Dart

## Panduan Menjalankan Aplikasi
1. Pastikan Flutter SDK sudah terpasang.
2. Jalankan `flutter pub get` untuk mengunduh dependensi.
3. Jalankan `flutter run` untuk memulai aplikasi.
